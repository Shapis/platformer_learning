# Platformer Learning Game

This project is a 2D platformer game developed in Unity3D using C#. The focus of the project is on software engineering principles, game system architecture, and algorithmic implementation rather than visual design.

## Overview

The game is built as a modular system composed of independent gameplay components. Core systems such as input handling, collision detection, state management, and AI pathfinding are implemented with clear separation of concerns to ensure maintainability and extensibility.

The project was developed end-to-end by a single author, from system design to implementation and debugging.

## Core Systems

- Player input processing and movement control
- Collision detection and physics interaction
- Game state and scene management
- AI navigation using A* and other graph-based pathfinding algorithms

## Architecture

The codebase follows a modular, system-oriented architecture using C# scripts in Unity. Gameplay logic is separated into distinct components, allowing systems to be developed and tested independently while maintaining clear integration boundaries.

Pathfinding logic is implemented using graph-based data structures, enabling flexible and reusable AI navigation across different levels.

## Technologies

- Unity3D
- C#
- Component-based architecture
- Graph-based algorithms (A*, pathfinding)

## Goals

- Apply software engineering principles in an interactive system
- Implement and evaluate algorithmic solutions in a real-time environment
- Build a maintainable and extensible codebase

## Future Improvements

- Improved AI behavior and navigation heuristics
- Additional gameplay systems and mechanics
- Performance optimization and refactoring
